**Description:**
Dial & Form is a deployed staging prototype for browsing a curated Rolex catalog. It pairs a 240-frame scroll-driven watch visual with a native JavaScript storefront, a Spring Boot REST API, PostgreSQL/Flyway persistence and Supabase Auth integration. Prices and stock are unconfigured, email delivery is still being verified, and the project does not process real payments.

**Technologies:** HTML, CSS, JavaScript, Canvas, Python standard-library server, Java 21, Spring Boot 3.3.4, Spring Data JPA, Spring Security, PostgreSQL 16, Flyway, H2 tests, Supabase Auth, Maven, Docker, Render and GitHub Actions.
